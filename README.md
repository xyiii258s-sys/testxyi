# 一个简单的机器遗忘示例

这个项目用 `sklearn` 的手写数字数据集演示机器遗忘的基本流程：

1. 使用完整训练集训练一个分类器；
2. 指定一个需要遗忘的类别；
3. 从训练数据中移除该类别，并在剩余数据上重新训练模型；
4. 对比遗忘前后的模型效果。

这里采用“从头重训”作为精确机器遗忘的基线。它实现简单、结果直观，适合入门；实际系统通常会进一步研究增量更新、梯度抵消和隐私评估等更高效的方法。

## 运行

安装依赖：

```bash
python -m pip install -r requirements.txt
```

遗忘数字 `3`（默认值）：

```bash
python machine_unlearning.py --forget-label 3
```

也可以指定遗忘多个类别：

```bash
python machine_unlearning.py --forget-label 3 7
```

输出会包含：

- 遗忘前模型在测试集上的准确率；
- 遗忘后模型在保留测试集上的准确率；
- 遗忘后模型在被遗忘类别测试集上的准确率和平均置信度；
- 被删除的训练样本数量。

注意：因为遗忘类别仍然可能出现在测试集中，所以遗忘后模型对该类别的预测不一定立刻变成零准确率；这里重点演示的是“训练数据删除后重新训练”的流程。
